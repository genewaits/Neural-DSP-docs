# Neural DSP Documentation Case Study

A technical writing portfolio project focused on product documentation, information architecture, and user experience.

## Project overview

This project analyzes and redesigns selected documentation for a Neural DSP audio plugin from the perspective of a technical writer.

The goal is to explore how product documentation can help users:

- understand the product;
- complete common tasks;
- troubleshoot common issues;
- find relevant information quickly.

## Scope

The project includes:

- documentation audit;
- user journey analysis;
- information architecture;
- terminology and consistency review;
- rewritten documentation examples;
- before/after analysis and rationale.

## Audience

The primary audience is musicians and producers using Neural DSP software, including users who may be unfamiliar with amp simulation and audio production workflows.
